# 接线清单 —— 照着接（第 3 篇，无光敏电阻版）

> 目标：4 条采集路径全部跑起来（I2C 光照 / I2C 气压温度 / 单总线温湿度 / 模拟 ADC）
> 配套：`FSP-配置清单-第3篇.md`（FSP 怎么配）、`接线表-排针版.md`（引脚出处与校验记录）
> 物料：面包板 + 杜邦线 + 电阻 + BH1750 + BMP280 + DHT11 或 DHT22

---

## 总览：只动两条排针

板子两侧共 4 条 8 脚排针，丝印标 `4 / 3`（左）和 `2 / 1`（右）。
**这次只用到「标 2」和「标 3」**，另外两条不碰。

| 步骤 | 从 | 到 | 需要 |
|---|---|---|---|
| 0 | 标 2 上丝印印着 `3V3` / `GND` 的两个孔 | 3V3 / GND 母线 | 2 根线 |
| 1 | 两颗 10k 串成分压 | **标 3 上丝印印着 `P014` 的那个孔** | 2 颗 10k + 3 根线 |
| 2 | DHT 数据线（带上拉） | **标 2 上丝印印着 `P402` 的那个孔** | 1 根线 + 1 颗 4.7k~10k |
| 3 | BH1750 + BMP280 的 SCL / SDA | **标 2 上丝印印着 `P408/301` 和 `P407/302` 的两个孔** | 4 根线 |
| — | 三个器件的 VCC / GND | 电源母线 | 6 根线 |

**合计约 16 根杜邦线 + 3 颗电阻**（DHT 用模块版的话少一颗）。

---

## 🔴 先记住这一条：**只认丝印上印的字，不要数第几个孔**

我前面写的"标 N 第 M 脚"用的是**接插件的引脚编号**，而**四条排针的引脚 1
不在同一头**：

| 排针 | 引脚 1 在哪 |
|---|---|
| 标 2 / 标 1 | 在**最上面**（所以"第 4 脚"= 从上往下第 4 个孔，对得上） |
| **标 3 / 标 4** | 在**最下面**（所以"第 6 脚"= 从上往下第 **3** 个孔，对不上！） |

实机就是这么踩的：按"标 3 第 6 脚"去数，数到了**第 7 个孔（P100）**，
而 P014 其实在**第 3 个孔**，导致分压怎么接都读出来是悬空。

**⇒ 接线时直接找脚旁边印的字：`P014`、`P402`、`P408/301`……
四条排针都按丝印从上往下的顺序列在下面，对着找就行。**

### 四条排针完整对照（**从上往下**，就等于你在板上看到的样子）

| 从上往下 | 标 4（左外） | **标 3（左内）** | **标 2（右内）** | 标 1（右外） |
|---|---|---|---|---|
| 第 1 个孔 | 3V3 | （空） | VIN | VIN |
| 第 2 个孔 | 3V3 | 3V3 | **3V3** ⬅ 母线 | 3V3 |
| 第 3 个孔 | P013 | **P014** ⬅ 分压中点 | **GND** ⬅ 母线 | GND |
| 第 4 个孔 | GND | P015 | **P408/301** ⬅ SCL | P002 |
| 第 5 个孔 | GND | P500 | **P407/302** ⬅ SDA | P200 |
| 第 6 个孔 | P103 | P101 | P000 | P301/408 |
| 第 7 个孔 | P104 | P100 | P001 | P302/407 |
| 第 8 个孔 | GND | P102 | **P402** ⬅ DHT | GND |

箭头标的就是这次要用的 6 个孔。

> **下面正文里凡是提到"标 N 上印着 `XXX` 的孔"，就按丝印字去找。**
> 偶尔还会带一句"从上往下第几个孔"作辅助 —— 两条对得上再下手。

## 第 0 步：先拉两条电源母线

| 从 | 到 |
|---|---|
| **标 2 上印着 `3V3` 的孔**（从上往下第 2 个） | 面包板 **3V3 母线**（红线） |
| **标 2 上印着 `GND` 的孔**（从上往下第 3 个） | 面包板 **GND 母线**（蓝/黑线） |

> **为什么主用标 2**：一条排针上就凑齐了 `3V3`(第2个孔) + `GND`(第3个孔) +
> `P408/301`+`P407/302`(第4、5个孔，就是 I2C) + `P402`(第8个孔) ——
> 电源、I2C、单总线全在这条上，面包板上最省线。
>
> 想多拉一路备份电源也行：**标 4 上印着 `3V3` 的两个孔**（从上往下第 1、2 个）、
> 以及**印着 `GND` 的三个孔**（从上往下第 4、5、8 个）。

## 第 1 步：模拟通道 A —— 两颗 10k 分压

**光敏电阻还没到，这一路先用固定分压，正好用来测 ADC 精度和噪声。**

```
                    ┌──[ 10kΩ ]── 3V3 母线
                    │
   标 3 上印着 P014 的孔 ─┤   （从上往下第 3 个孔）
   (P014 / AN012)        │
                         └──[ 10kΩ ]── GND 母线
```

| 从 | 到 |
|---|---|
| 3V3 母线 | 电阻 A 一端 |
| 电阻 A 另一端 | **标 3 上印着 `P014` 的那个孔**（从上往下第 3 个）**＋** 电阻 B 一端 |
| 电阻 B 另一端 | GND 母线 |

**理论电压 = 3V3 × 10k/(10k+10k) = 1650 mV**（对应 ADC 读数 2048 LSB），
上板后自检会拿实测值跟它比。

### 🔴 这里有一个必看的坑：别跨过面包板的中间槽

**面包板中间那条槽把每一列切成互不相通的两半**（上半 a~e、下半 f~j）。
插错侧的后果是"**丝印看着在同一列，电气上却是两个孤立节点**"：

```
      ❌ 错的                          ✅ 对的
  ┌── a ── R1 的腿             ┌── a ── R1②
  ├── b ── 中点跳线             ├── b
  ├─ 中间槽（不连通）─         ├── c ── R2① 和 中点跳线
  ├── c ── R2 的腿             │
  └── d ──                     └── d ──
```

**⇒ 分压的两颗电阻腿 + 中点引出的跳线，三者必须全在中间槽的同一侧。**

这个坑实机踩过：分压明明按上面接的，P014 却一直读悬空
（`sigma 42~298 LSB`，而接好的低阻源应该是个位数），
原因就是电阻腿和跳线分散在槽的两侧。

**验证办法（板子通电，万用表）**：

| 量什么 | 应该读到 |
|---|---|
| 分压**中点那一列**任意一孔 ↔ GND | **≈1650 mV** |
| P014 跳线在面包板上插的那个孔 ↔ GND | 和上面**一样** |

不一样 ⇒ 跳线没插在中点那一列的同一侧。

> DHT 的电源脚和 I2C 那两个模块同理：**它们的引脚都插在 row f 那一排，
> 所以那些线也都在下半区**，不要跟上半区的分压混着插。

> ⚠️ **标 3 这条排针上没有 GND**（印着  的那个孔下面、以及最下面那个孔都是 /空，没有 GND）。GND 要从母线引过来。
>
> 💡 **两颗等值电阻无所谓"上下接反"** —— 10k/10k 是对称的，换了也一样是 1650 mV。
> 想让自检真正验出分压方向，就把其中一颗换成 20k：
> `3V3─[20k]─┬─P014 / └─[10k]─GND` 理论 **1100 mV**；
> 若读到 **2200 mV** 就说明上下臂反了。**换完记得同步改 `app_config.h` 的
> `APP_FIXED_R_HIGH_OHM` / `APP_FIXED_R_LOW_OHM`**，否则自检会拿错误的期望值去比，
> 反而误报"误差过大"。

## 第 2 步：DHT11 / DHT22 —— 单总线

```
   VCC ── 3V3 母线
   GND ── GND 母线
   DATA ─┬─ 标 2 上印着 P402 的孔
         └─[ 4.7k~10k ]── 3V3 母线      ← 模块版一般自带，裸传感器必须自己加
```

| DHT 引脚 | 接到 |
|---|---|
| VCC | 3V3 母线 |
| GND | GND 母线 |
| DATA | **标 2 上印着 `P402` 的孔** |

> ⚠️ **型号要和代码对上**：`src/app_config.h` 里 `APP_DHT_TYPE` 现在写的是 **11**。
> 你手上是 DHT22 的话把它改成 **22**（协议一样，只是数据格式不同 —— DHT11 是整数，
> DHT22 是 16 位带小数）。改一个数字就行，不用动驱动。
>
> ⚠️ 上拉电阻不能省。裸的四针传感器不加，读数会一直超时。

## 第 3 步：I2C 两个器件（BH1750 + BMP280）

两个器件**共用同一条总线**，靠 ADDR / SDO 引脚区分地址。

| 器件 | 器件引脚 | 接到 |
|---|---|---|
| **BH1750** | VCC | 3V3 母线 |
| | GND | GND 母线 |
| | SCL | **标 2 上印着 `P408/301` 的孔** |
| | SDA | **标 2 上印着 `P407/302` 的孔** |
| | ADDR | **GND**（→ 地址 `0x23`；接 VCC 则是 `0x5C`，代码两个都试） |
| **BMP280** | VCC | 3V3 母线 |
| | GND | GND 母线 |
| | SCL | 与 BH1750 的 SCL 并联 |
| | SDA | 与 BH1750 的 SDA 并联 |
| | SDO | **GND**（→ 地址 `0x76`；接 VCC 则是 `0x77`，代码两个都试） |
| | CSB | 接 3V3（BMP280 用它选 I2C 模式）—— 模块版通常已处理好，裸芯片必须自己接 |

✅ **上拉电阻不用自己加** —— 原理图里板载已有 `R26 = 4K7`。

> 同样信号在「标 1」上印着 `P301/408`、`P302/407` 的两个孔也各有一份，接哪边都行。

## 第 4 步：光敏电阻（LDR）→ P015 —— 2026-10-09 已接

| LDR 分压 | 接到 |
|---|---|
| LDR 一端 | **3V3 母线** |
| LDR 另一端 + 10k 一端（拧一起） | **标 3 上印着 `P015` 的孔**（从上往下第 4 个） |
| 10k 另一端 | GND 母线 |

⚠️ **上下臂别反**：LDR 在上、10k 在下 —— 越亮引脚电压越高。
（接反读数会往相反方向走，一眼能看出来。）

`APP_ADC_B_ENABLE` 已置 `1`，上报从 raw/mV 升级为 **raw/mV/lux**。

> 历史备注：这个口原来是给 MQ-2 的备胎 —— AO 是 0~5V，用的话必须先分压到 3.3V 以内；
> 加热丝还得从 `VIN`（标 2 第 1 脚）取 5V。

## 上电前：3 个检查（30 秒，能省掉一次烧板）

| # | 怎么量 | 期望 |
|---|---|---|
| 1 | 蜂鸣档量「3V3 母线 ↔ GND 母线」 | **不响**。响了就是短路，先查再上电 |
| 2 | 电阻档量「**标 2 上印着 `P408/301` 的孔** ↔ 3V3 母线」 | **≈ 4.7kΩ** |
| 3 | 电阻档量「**标 2 上印着 `P402` 的孔** ↔ 3V3 母线」 | **≈ 4.7k~10kΩ**（DHT 上拉） |

### 第 2 项是本次唯一真正的未知

板子在 `P301/P302` 和 `P407/P408` 之间留了 **0Ω 选焊电阻**，所以排针上那两脚
丝印才写成 `P301/408`、`P302/407` —— **装的是哪一档必须实测**。

| 量出来 | 说明 | 动作 |
|---|---|---|
| **≈4.7kΩ** | 这两脚确实在 I2C 网络上，走的是 P301/P302 | 直接上电，什么都不用改 |
| 量不到 / 不通 | 当前档位走的是 P407/P408 | 见下方"如果 I2C 不通怎么办" |

### 如果 I2C 不通怎么办

**先别急着动 0Ω 电阻。** 两步走：

1. 先上电跑一遍，看自检的 `[I2C] --- I2C bus scan ---` 有没有扫到 `0x23` / `0x76`。
   扫到了就说明不用管焊接档位。
2. 扫不到的话，回 e² studio 把 I2C 的两脚从 `P301/P302` 改成 `P407/P408`
   —— **但这两脚默认被 CTSU 占着**（`ra_gen/pin_data.c` 里配成了 CTSU），
   得先在 `Pins` 标签页里把它们从 CTSU 释放。
   第 2 篇的触摸只用 P206 和 P409 当电极，放掉 P407/P408 不影响它。
