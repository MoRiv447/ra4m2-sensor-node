# WiFi MCU 接入 —— 操作清单（2026-10-10）

目标：RA4M2 通过 **SCI2（P301/P302）** 驱动 DA16200 WiFi 模块，打通
「MCU → WiFi → broker.emqx.io → MQTTX（`notmes/ra4m2`）」云链路（第 4 篇第三路数据访问）。

> 前置已就绪：FSP 的 `g_uart2`（SCI2、115200、回调 `wifi_uart_callback`）✓；
> `wifi_bridge.c` 已就位（开机发 `AT` + `AT+NWMQCL=1`；之后每 10s 发 `AT+NWMQMSG=…`）✓；
> 栈溢出已修复（主栈 4KB）✓ —— 本清单只剩「接线 + 上电 + 联调」。

---

## 一、接线（改线前先断电；USB-TTL 工具就此退役）

### 1. 模块侧 4 根（若已拆散就按此接回；若还插着就核对）

| 从 | 到 | 作用 |
|---|---|---|
| 面包板 **3V3 母线** | J1 第 1 根（VCC） | 供电（原来由工具供的话，改从母线取） |
| 面包板 **GND 母线** | J1 第 2 根（GND） | 共地（必须） |
| 信号线甲 | J1 **第 5 根**（= 原"工具 TXD"孔那根） | 留到下一步接 MCU |
| 信号线乙 | J1 **第 4 根**（= 原"工具 RXD"孔那根） | 留到下一步接 MCU |

### 2. MCU 侧（工具退役，两根信号线改到 MCU）

| 从（RA4M2 侧） | 到（模块侧） | 作用 |
|---|---|---|
| **P301**（标 1 排针第 6 孔，RXD2） | 信号线甲（模块第 5 根） | 模块发 → MCU 收 |
| **P302**（标 1 排针第 7 孔，TXD2） | 信号线乙（模块第 4 根） | MCU 发 → 模块收 |

> **为什么这样对**：MCU 的 RX 接"模块发"线、TX 接"模块收"线（标准交叉）。
> 工具板上"TXD/RXD"孔的叫法是 ESP-01S 工具板"按目标端命名"的历史遗留，
> 别按字面理解，按本表接即可。

### 3. 容错与供电

- 接好后模块无任何回话 → **把 P301 / P302 两根信号线对调**再试（3.3V 电平，安全）。
- 电源线用**短而粗**的跳线；可选：模块 VCC–GND 就近并 10µF + 0.1µF 去耦
  （DA16200 发射瞬间峰值 280~320 mA）。

## 二、上电顺序（关键）

1. 全部接好 → 上电；
2. **等约 10 秒**（模块启动 + 入网；MCU 开机瞬间发的前两条命令会撞上"模块还没起好"）；
3. **按一下板上 RESET 键**（模块不断电）→ MCU 重启、重发握手 —— 让"轻启动"序列
   落到模块已就绪的时刻；
4. 观察串口 20~30 s，对照下一节判读。

> 如果还没按复位就已经出现 `+NWMQCL:1`（模块启动足够快时有可能），第 3 步可跳过。

## 三、预期输出（判读表）

| 串口出现 | 含义 |
|---|---|
| `[WiFi] << +INIT:DONE,0` | 模块启动完成 —— **接线 + 供电正确** ✓ |
| `[WiFi] << OK`（其实际回什么以模块为准） | 模块应答 AT —— 命令通道双向通 ✓ |
| `[WiFi] << +NWMQCL:1` | **MQTT 已连上 broker**（关键；单测时约 2.8 s 出现） |
| `[WiFi] << +NWMQMSGSND:1` | 每 10s 一帧上报发送成功 ✓ |

同时在电脑 **MQTTX**（订阅 `notmes/ra4m2`、QoS1）上：每 10s 收到一帧
`RA4M2;lux=…;ldr=…;T=…;RH=…`（示例：`RA4M2;lux=11.7;ldr=8.3;T=24.6;RH=52.7`）。

> 注（2026-10-10 已改）：上报帧现含**两个光照字段** —— `lux=`（BH1750 标定值）+
> `ldr=`（LDR/P015 的幂律估算值）。此前的固件里 `lux` 恒为 0.0（取值遗留），
> 该项已修复，随下次构建生效。

## 四、分支处理（三种失败）

| 现象 | 判断 | 动作 |
|---|---|---|
| 等 30s，一条 `[WiFi] <<` 都没有 | 接线 / 供电 | 查 4 根线 → 对调两根信号线 → 量 J1 第 1 根对 GND = 3.3V → 复位重试 |
| 有 `+INIT:DONE,0` / AT 有回，但 NWMQCL 无 `+NWMQCL:1` | 配网/配置掉电丢失 | **停手报我** —— 我补"全量配网序列"（含 SSID/密码，单独处理） |
| 命令都有回但 MQTTX 收不到 | 订阅侧 | 检查 topic/QoS；把串口 `+NWMQMSGSND` 结果发我 |
