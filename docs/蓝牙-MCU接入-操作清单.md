# 蓝牙 MCU 接入 —— 操作清单（2026-10-09）

目标：RA4M2 通过 **SCI0** 驱动 DA14531 蓝牙模块，打通「MCU ↔ 手机」链路。

---

## 一、接线（先拔掉 USB-TTL 的 USB 线再动手）

### 拔掉 4 根（USB-TTL 全部退役）
- 蓝牙底板 J1 上原「工具」接的 **TXD、RXD、3V3、GND** 四根线全部拔掉，
  USB-TTL 整块收起来 —— 成品形态：蓝牙的所有连线都从面包板（RA4M2）来。

### 接上 4 根（全部从面包板母线取）

| # | 从（RA4M2 侧） | 到（蓝牙 J1） | 作用 |
|---|---|---|---|
| 1 | 面包板 **3V3 母线** | J1 的 VCC 脚（脚 6 或 12，即原工具 3V3 插的那根） | 蓝牙供电 |
| 2 | 面包板 **GND 母线** | J1 的 GND 脚（脚 5 或 11，即原工具 GND 插的那根） | 共地 |
| 3 | **标 3 排针 从上往下第 6 孔**（P101 / TXD0） | 左列 从上往下 **第 5 根**（脚 2 / RXD） | MCU 发 → 模块收 |
| 4 | **标 3 排针 从上往下第 7 孔**（P100 / RXD0） | 左列 从上往下 **第 4 根**（脚 3 / TXD） | 模块发 → MCU 收 |

> 标 3 排针数法：**只认"从上往下"的视觉顺序**（该表已经按视觉顺序修正过，
> 别再按接插件脚号数——第 3 篇踩过这个坑：数错一个孔，怎么接都悬空）。

### 保持不动
- **LPR 拉高**（J1-9 ↔ J1-12）：12 脚现在改由面包板 3V3 供电，拉高依然有效
- J3 跳线帽（P+ 侧）
- 面包板上 LDR / I2C 那一堆线（别碰）

### 供电方式（两种，接线完全相同，只差 J3 跳线帽位置）

| 方式 | J3 跳线帽 | 说明 |
|---|---|---|
| A · 排针供电 | 插 **[P+ 侧]**（左两针） | 面包板 3V3 经 J1 VCC 给模块供电 |
| B · 电池供电 | 插 **[B+ 侧]**（右两针） | 底板 BT1 纽扣电池供电；J1 的"面包板 3V3"线**降级为 LPR 拉高电平源**（P+ 轨与模块已被跳线帽隔离，不会双供电） |

> ⚠️ **无论哪种方式，GND（J1-5/11 ↔ 面包板 GND）都必须接**——有线 UART 信号必须有
> "共同参考地"；两个地不互通时，电平信号失去参照、通信必然不工作。
> （BLE 无线连接不需要线，**但 UART 有线连接必须有地**；若出现不稳先怀疑电池电量。）

### 容错（重要）
- 接好后若 MCU 侧发 AT 无响应 → **把第 3、4 两根信号线对调**再试
  （3.3V 电平不会烧；这块板子有"接法前科"，对调是终结它的最后一步）
- 回退方案：若需独立验证蓝牙模块本身，重插 USB-TTL 的 4 根线即可（3 秒切换）

## 二、FSP 配置（e² studio 里操作）

1. 双击工程根目录的 `configuration.xml` → 上方切到 **Stacks** 页
2. **New Stack → Driver → Connectivity → UART (r_sci_uart)**
3. 选中新栈（右出现 Properties），改这几项：
   - **Name**: `g_uart0`（对齐工程现有的 g_uart9 命名）
   - **Channel**: `0`
   - **Callback**: `bt_uart_callback`
   - **Baud Rate**: `115200`
   - Data Bits `8` / Parity `None` / Stop Bits `1` / Flow Control `None`
4. 切到 **Pins** 页，确认 P100 = RXD0、P101 = TXD0（SCI0）；
   若未自动分配，手动点这两脚选 SCI0 信号
5. 右上角 **Generate Project Content**
6. 完事喊我
